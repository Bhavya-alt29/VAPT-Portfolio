# Networking

## Overview

This repository documents my learning and practical understanding of Computer Networking, starting from fundamental concepts to advanced networking technologies.

It covers network architecture, communication models, IP addressing, protocols, routing, switching, network infrastructure and network security.

The objective is to build a strong networking foundation and apply these concepts in Cybersecurity, Vulnerability Assessment and Penetration Testing (VAPT).
