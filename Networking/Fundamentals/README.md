# Networking Fundamentals

## 1. What is Computer Networking?
Computer networking is the process of connecting two or more devices to communicate and share resources such as files, data, and services.

## 2. Types of Networks
- PAN – Personal Area Network
- LAN – Local Area Network
- WLAN – Wireless Local Area Network
- MAN – Metropolitan Area Network
- WAN – Wide Area Network

## 3. Network Architectures
- Client-Server Architecture
- Peer-to-Peer (P2P) Architecture

## 4. Network Topologies
- Bus
- Star
- Ring
- Mesh
- Tree
- Hybrid

## 5. Networking Devices
- Router
- Switch
- Hub
- Firewall
- Access Point
- Modem

## 6. Security Relevance
Understanding networking fundamentals helps security testers identify network boundaries, communication paths, exposed services, and potential attack surfaces.
