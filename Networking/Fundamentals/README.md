# Networking Fundamentals

## Overview

Networking fundamentals cover the basic concepts of how computers and other devices connect, communicate and exchange information over a network. Understanding these concepts helps explain how data travels between devices, how networks are structured and how different networking components work together.

## 1. Computer Networks
A computer network is a group of two or more devices connected to communicate and share resources such as files, data, applications and internet access.

## 2. Types of Networks
Networks are classified based on their geographical coverage and purpose.

- **PAN (Personal Area Network):** Connects personal devices over a short distance, such as a phone and smartwatch.
- **LAN (Local Area Network):** Connects devices within a limited area, such as a home, office or building.
- **WLAN (Wireless Local Area Network):** A LAN that uses wireless communication, typically Wi-Fi.
- **MAN (Metropolitan Area Network):** Connects networks across a city or metropolitan area.
- **WAN (Wide Area Network):** Connects networks across large geographical areas. The Internet is the largest example.

## 3. Network Architectures

Network architecture describes how devices communicate and share resources.

- **Client-Server Architecture:** A client requests services or resources, and a central server processes the request and provides a response.
- **Peer-to-Peer (P2P) Architecture:** Devices communicate and share resources directly without depending on a central server.

## 4. Network Topologies

Network topology describes how devices are physically or logically arranged and connected within a network.

- **Bus:** All devices share a single communication cable.
- **Star:** All devices connect to a central switch or hub.
- **Ring:** Devices are connected in a circular arrangement.
- **Mesh:** Devices are connected through multiple communication paths.
- **Tree:** Devices are arranged in a hierarchical structure.
- **Hybrid:** Combines two or more network topologies.

## 5. Network Devices

Network devices help connect systems, forward data, control traffic and enable communication.

- **Router:** Connects different networks and forwards packets based on IP addresses.
- **Switch:** Connects devices within a LAN and forwards frames using MAC addresses.
- **Hub:** Connects multiple devices and broadcasts incoming data to all connected ports.
- **Bridge:** Connects network segments and filters traffic using MAC addresses.
- **Repeater:** Regenerates signals to extend network communication distance.
- **Gateway:** Connects networks that may use different protocols or communication systems.
- **Firewall:** Monitors and filters network traffic based on security rules.
- **Access Point:** Allows wireless devices to connect to a wired network.
- **Modem:** Converts signals to enable communication over an internet service provider's connection.
- **NIC:** Network Interface Card enables a device to connect to a network.

## 6. MAC Address

A MAC (Media Access Control) address is a hardware address assigned to a network interface. It is primarily used for identifying devices within a local network at the Data Link Layer.

## 7. IP Address

An IP (Internet Protocol) address is a logical address assigned to a device or network interface to identify it and enable communication across networks.

- **Public IP:** An address used to identify a network or device on the public internet.
- **Private IP:** An address used within private networks and not directly routable over the public internet.
- **IPv4:** Uses a 32-bit address, represented in dotted decimal format.
- **IPv6:** Uses a 128-bit address to provide a much larger address space.
- **Static IP:** An IP address configured to remain fixed.
- **Dynamic IP:** An IP address assigned automatically, commonly through DHCP.

## 8. Default Gateway

A default gateway is the network device, usually a router, that forwards traffic from a local network to destinations outside that network when no more specific route is available.

## 9. Subnet Mask

A subnet mask identifies which portion of an IPv4 address represents the network and which portion represents the host. It helps devices determine whether a destination belongs to the local network or another network.

## 10. DNS (Domain Name System)

DNS translates human-readable domain names, such as google.com, into IP addresses that computers use to communicate with servers.

## 11. Security Relevance

Understanding networking fundamentals is essential for cybersecurity and penetration testing. It helps security testers understand network communication, identify devices, recognize network boundaries, discover exposed services and understand potential attack surfaces.
